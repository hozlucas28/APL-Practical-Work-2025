## Resumen

Este repositorio contiene el trabajo práctico de APL para la materia Virtualización de Hardware de la [Universidad Nacional de La Matanza (UNLaM)](https://www.unlam.edu.ar/). Este trabajo práctico consiste en desarrollar una serie de cinco scripts en [Bash](https://www.gnu.org/software/bash/) y [PowerShell](https://learn.microsoft.com/en-us/powershell/), aprendiendo cómo crear scripts para automatizar tareas.

### Scripts

|  #  | Tópico                                                          |                                        |
| :-: | :-------------------------------------------------------------- | :------------------------------------: |
|  1  | Análisis de resultados de encuestas de satisfacción de clientes | [Consigna](./exercises/exercise-01.md) |
|  2  | Análisis de rutas en un mapa de transporte                      | [Consigna](./exercises/exercise-02.md) |
|  3  | Conteo de eventos en logs de sistemas                           | [Consigna](./exercises/exercise-03.md) |
|  4  | Análisis de seguridad de código en repositorios Git             | [Consigna](./exercises/exercise-04.md) |
|  5  | Buscador de información de países                               | [Consigna](./exercises/exercise-05.md) |
